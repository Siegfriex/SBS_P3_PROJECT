# 답변행태 Taxonomy v1.0

이 사전은 기관 측으로 명시적으로 분류된 answer unit에만 적용한다. `위원이 아니면 답변자` 같은 else 규칙은 사용하지 않는다.

| 코드 | 관찰형 라벨 | 자동 후보 예시 |
|---|---|---|
| A1 | 기억 부재 진술 | 기억이 나지 않는다 |
| A2 | 정보 미보유·확인 필요 | 확인해 보겠다 |
| A3 | 타기관·타주체 귀속 | 소관이 아니다 |
| A4 | 질문 비직접 대응 | 공감한다·유념하겠다만 존재 |
| A5 | 검토·협의 유보 | 검토·협의하겠다 |
| A6 | 조사·자료 제출 절차 | 조사·서면답변·자료제출 |
| A7 | 구체 조치 약속 | 일정·개선·개정·계획 |
| A8 | 완료·근거 제시 | 완료·시행·수치·문서 근거 |

모든 적중은 offset과 evidence span을 저장한다. 부정·인용·의문 맥락은 suppress하고, `관계기관과 협의`만으로 A3를 부여하지 않는다. 한 답변은 다중라벨일 수 있다. 자동 결과는 `weak_rule`이며 Gold가 아니다.
